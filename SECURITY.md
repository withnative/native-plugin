# Security policy

Report suspected vulnerabilities through this repository's private vulnerability reporting
flow under **Security → Advisories → Report a vulnerability**.

Include the affected component and version, reproduction steps, impact, and any suggested
mitigation. Do not include live credentials, bearer tokens, or workspace data. Do not disclose
an unpatched vulnerability in a public issue.

Ordinary installation and support questions belong in public issues once the repository opens
them. Security reports about the independently deployed Native service may be redirected to the
service owner after private triage.
